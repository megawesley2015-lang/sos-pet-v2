# Ícones PWA - SOS Pet

## Gerar ícones automaticamente

1. Instale o sharp:
```bash
npm install sharp --save-dev
```

2. Execute o script:
```bash
node scripts/generate-icons.js
```

## Ou gere manualmente

Use um gerador online como:
- https://www.pwabuilder.com/imageGenerator
- https://realfavicongenerator.net/
